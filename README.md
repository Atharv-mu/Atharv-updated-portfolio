# 🌐 Atharv Holkar — Personal Portfolio

Welcome to my **personal portfolio website**.

This is the **second updated version** of my portfolio, built as a single HTML file with embedded CSS and JavaScript. The website combines a personal portfolio with an interactive **Tic-Tac-Toe game**, which visitors need to complete before accessing the portfolio.

## 🚀 Live Portfolio

The portfolio is designed to showcase my:

* 👨‍💻 Skills and interests
* 💼 Experience
* 🚀 Projects
* 🎓 Education
* ✍️ Personal journey and blogs
* 🔗 Professional and social profiles

## 🎮 Interactive Entry Screen

Instead of opening directly into the portfolio, visitors first encounter a Tic-Tac-Toe game.

The idea is simple:

> **Beat the system to unlock my portfolio. 🎯**

After the game ends, the **Access Portfolio** button appears and takes the visitor to the main portfolio.

### Game Features

* Single-player Tic-Tac-Toe
* Player uses `X`
* Computer uses `O`
* Random computer moves
* Win detection
* Draw detection
* Portfolio unlock after the game
